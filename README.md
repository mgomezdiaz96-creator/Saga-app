# Saga

Saga makes it easier to explore things you want to learn through approachable, self-paced curricula. Each path brings together books, podcasts, articles, activities, and prompts, with room to save resources and share interests with friends.

This hackathon prototype is a static web app in `index.html`; it needs no package installation or build step.

## Run locally

Open `index.html` in a browser.

## Publish with GitHub Pages

After pushing this repository to GitHub, open **Settings → Pages**, choose **Deploy from a branch**, select the default branch and the `/ (root)` folder, then save. GitHub Pages will publish `index.html` as the site entry point.
